# Изображения

## `developer.jpg` — фотография разработчика

Положите сюда фотографию под именем **`developer.jpg`** (подойдёт и `.png` —
тогда поменяйте расширение в `js/app.js`, константа `DEV_PHOTO`).

Обрезать файл вручную не нужно: круглая рамка и кадрирование «лицо и плечи»
делаются стилями. Если кадр встал неточно, подправьте две переменные
в `css/style.css`, блок «КАРТОЧКА РАЗРАБОТЧИКА»:

* `--dev-zoom` — насколько приблизить снимок (больше значение — крупнее лицо);
* `--dev-y` — вертикальное смещение кадра (меньше процент — кадр выше).

Пока файла нет, на его месте показываются инициалы — страница не ломается.

После добавления файла пересоберите однофайловую версию: `node build.js`.
Сборщик встроит фотографию в `dist/index.html` как data-URI, чтобы страница
работала одним файлом.
